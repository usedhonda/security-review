# Security Review result inbox

This tracked document is the stable display anchor for aggregated Code scanning reports. It contains no findings or target source code.

Actual findings are stored in the central repository's access-controlled Security/Code scanning view. Their text identifies the real target repository, immutable source commit, original filename/line range, evidence, impact and proposed fix. The displayed location here is an inbox anchor, not a claim that the target vulnerability is in this document. Native inline target-repository annotations and autofix are not supplied by this mode.

`Security Review Hub Check` entries are synthetic transport/access tests, never vulnerabilities. `Security Review Account` summary entries describe bounded selected-file review; zero findings is not proof that the whole repository is safe.

Do not commit detailed findings to this file. See [account workflow and limits](ACCOUNT_REVIEW.md).
